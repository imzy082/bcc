# 风格研究

用户要求从一个或多个视频提炼风格、调性或创作指南时读取。

## API 工作流

确认全部素材路径及宿主环境变量，用 Google 官方 Gemini 同时分析视频画面与音轨：

```bash
node "$BCC" analyze <视频1> <视频2> --task research --out <成品目录>/风格指南.md
```

未指定模型时使用宿主 `GEMINI_MODEL`。结果 md 即成品，无需再次导出；不支持 `--master`，也不读取本地研究配置。

此入口直接上传全部视频并在一次请求中综合分析；旧 `research` 命令先分析图片，不能用来替代视频入口。文件或上下文超限时报告错误，在用户认可后减少单次素材或分段；不得静默只研究部分视频。

## 结果检查

- 包含制作风格、剧本风格、镜头语言分析、创作建议四个一级标题。
- 每条视频都应有具体证据；结论注明视频编号与时间戳，区分共性和差异。
- 检查光线色彩、剪辑节奏、运镜、叙事、对白、音乐/音效及音画关系；无音轨的素材明确说明，不能猜测声音。
- 创作建议应是可执行的拍摄剪辑方法，不能只有风格形容词。
- 文件存在或结构正确不证明内容完全准确；未实测或回看核验的部分如实说明。

## 用户明确选择宿主 Agent 模式

确认宿主能实际接收视频及音轨，逐条分析全部原视频，再按上述要求输出 md。可用 `shots --no-config --no-frames` 辅助时间轴。只有看图能力时先说明音频分析缺口，不能自动改用关键帧并声称完整研究。
