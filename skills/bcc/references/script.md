# 剧本 / 台词

用户要求拆剧本、对白或台词时读取。默认按 SKILL.md 的 Gemini API 模式执行。

## API 工作流

1. 用 `probe --no-config` 检查时长及是否含音轨，确认宿主环境变量和用户指定模型。
2. 调用视频分析；用户指定模型时传 `--model`，未指定时使用宿主 `GEMINI_MODEL`：

```bash
node "$BCC" analyze <视频> --task script --out <工作目录>/剧本.md
```

可加 `--master <大师ID>`；管线会注入对应方法论，不需另拼一份 prompt。视频压缩、上传、分段和失败由 CLI 处理，不能让宿主凭图片替写。

3. 读取结果核对场景时间戳、说话人、画面描述和对白；再导出：

```bash
node "$BCC" export script --no-config --from <工作目录>/剧本.md --out <成品目录>/剧本.docx --format docx,md,html --video <视频>
```

## 结果检查

- 场景时间戳须递增且在视频时长内；首场及结尾不能明显缺失。
- 每句对白尽量完整转写，区分说话人、旁白和画外音；听不清须标注，不以字幕或猜测补造音轨内容。
- 使用 `[HH:MM:SS] 编号 场景`、`△ 画面描述`、`人物：对白`，字幕用 `【字幕：…】`。
- 输出明显过短、大片时间空缺、缺少人物或出现“未听到音频”的说明时，核实源视频是否含音轨及实际调用状态；不能只看文件存在就交付。
- 结构检查不能证明逐句识别准确；未经回看/用户核验，不声称完全无遗漏。需要再调用 API 时保留问题与重试原因。

## 用户明确选择宿主 Agent 模式

确认宿主可实际接收完整视频和音轨，再完整分析视频并写 md；可用 `shots --no-config --no-frames` 校准时间轴、`master <id> --kind script` 获取方法论，最后按上方命令导出。若宿主无法接收视频或音频，说明能力缺口，不以图片冒充视频分析。
